# Wspólna publikacja DoRoboty.ai

Ten katalog zawiera źródła łączące zaakceptowany landing, portal i profil.
Nie przesyłaj go do Netlify.

Uruchom `npm run build:publication`, a potem `npm run preview:publication`.
Podgląd: http://127.0.0.1:3015/ . Do Netlify przesyła się cały wygenerowany
folder **publish** w katalogu aplikacji. Zawiera landing, portal i profil.

Świeży profil pokazuje fikcyjną Annę i przykładowy projekt. Wcześniejsze dane
z localhost nie przechodzą automatycznie na inny adres. W razie potrzeby przenieś
scenariusz przez eksport/import. Wszystkie dane muszą być fikcyjne.

Po publikacji sprawdź publiczny adres, widoczność i zapis/odczyt profilu.
Lokalny raport nie potwierdza ustawień Netlify.
