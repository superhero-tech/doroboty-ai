# Structured project contribution prototype

Intent: help a recruiter distinguish personal work, shared work and work owned by others before inviting a candidate. Implement a scoped, frontend-only workshop at `/#/opis-projektu`; do not change existing application submission or score candidates. Keep I2 available as a separate discovery concept.

Acceptance: accessible labelled inputs, explicit personal/shared responsibilities, decision ownership, result provenance and unknowns; optional evidence with safe HTTP(S) links; validated recruiter preview; editable incomplete local draft with reload recovery and visible storage errors; synthetic example; no requests or submissions. The workshop is shared locally, separate from persona records, and says so. Reuse Base UI Button/Input and host Textarea. Adapt C01/C02/C03/C13/C22 with outlined r24 white surfaces, paper, ink, pink actions, Geist Serif 400 headings and scoped mobile stacking; do not modify the immutable kit or global primitives.

Validation planned: schema regression tests, browser form/error/preview/edit/save/reload/blocked-storage checks, desktop/mobile/keyboard comparison against local reference controls, full `npm run check` (Windows equivalent of scripts/verify). Record actual outcomes below. Prototype observations from real people remain uncollected. Metrics and proposed thresholds are documented separately in the project, not represented as measured results.
